Privacy

Updated 21 November 2026.

AERONEX has no accounts, no analytics and no server of its own. What you enter stays on your computer. A few things are fetched from the internet when you use the features that need them; this page lists every one.

What stays on your computer

Your name from the first-run setup, aircraft profiles, frame designs, mission plans, flight logs and settings are stored in your Windows user folder, at %APPDATA%\AERONEX. In the app, Help, then Where my data is kept, opens it. API keys you enter are encrypted by Windows for your user account before they are saved.

Settings, then Reset app data, deletes all of it. Uninstalling AERONEX leaves it in place, so a reinstall picks up where you left off; delete the folder to remove it.

What leaves your computer, and when

  • Looking for updates. When AERONEX starts and every four hours, it asks GitHub whether there is a newer version, and downloads it from GitHub if there is. Like any web request, this tells GitHub your IP address. Nothing about you or your aircraft is sent.
  • Installing firmware. Only when you use the Firmware page: the firmware list and the build for your board come from ArduPilot's server, firmware.ardupilot.org.
  • Maps. Only when a map is on screen: map pictures and ground heights come from the provider you choose, such as Sentinel-2 cloudless by EOX, OpenStreetMap, Esri World Imagery, MapTiler (with your own key), or Terrain Tiles on AWS. Each receives the map area being shown.
  • The assistant. Only if you add your own Anthropic API key: your questions and the aircraft's readings, never its location, go to Anthropic to be answered, under your own account with them.
  • Links. Documentation and other links open in your web browser, not inside AERONEX.

Nothing else is sent. The flight controller is reached only over your USB cable or telemetry radio.

This website

The site is hosted by Vercel, which keeps standard request logs. It sets no cookies and has no analytics. To show the newest version, your browser asks GitHub's public API for the latest release.

Questions

Ask on the project's GitHub issues. To report a security problem privately, use Security, then Report a vulnerability.
