Code signing policy

How releases are signed

Updated 21 November 2026

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: AERONEX has applied to SignPath Foundation. Until the application is approved, installers are not signed, and Windows shows "Windows protected your PC" when you run one: choose More info, then Run anyway. Versions up to and including 0.3.5 are not signed. This page will say from which version installers are signed.

What is signed

Only the Windows installer, AERONEX-Setup-<version>.exe, built from the public source code of this project at github.com/Dwijvyas-9926/AERONEX. Each installer carries the product name AERONEX and its version number in its file details.

The installer includes open-source components from other projects, such as Electron and Chromium, listed in THIRD-PARTY-NOTICES.txt in the install folder. Their files are shipped as their authors published them and are never signed with this project's certificate.

How a release is built and approved

  • Built by GitHub. Every installer is built by the project's GitHub Actions workflow on runners hosted by GitHub, from the commit the release is tagged with. Nothing built on a personal computer is signed.
  • Submitted for signing. The workflow sends the installer to SignPath, which records where and how it was built.
  • Approved by hand. An approver checks each signing request and approves it before anything is signed. Requests are never approved automatically.
  • Published. Only after signing is the release published on GitHub, where installed copies of AERONEX find their updates.

Team roles

  • Committers and reviewers: Dwij Vyas
  • Approvers: Dwij Vyas

Every team member uses multi-factor authentication on GitHub and on SignPath.

Privacy

AERONEX sends nothing about you or your aircraft to anyone. To look for updates it contacts GitHub when it starts and every four hours. It contacts other services only when you use a feature that needs them: ArduPilot's firmware server when you install firmware, the map provider you choose when a map is on screen, Windows' location service only when you press My location on a map, and Anthropic only if you add your own API key for the assistant. The privacy page lists each of these.

Checking an installer

For a signed release, right-click the downloaded installer, choose Properties, then Digital Signatures: the signer is SignPath Foundation. In PowerShell, Get-AuthenticodeSignature .\AERONEX-Setup-<version>.exe shows Valid and the same signer.

Download AERONEX only from this website or the project's GitHub releases.

Reporting a problem

If an installer's signature looks wrong, or you find a security problem, report it privately through Security, then Report a vulnerability, or write to aeronexstation@gmail.com.
