AERONEX for Windows can now keep itself up to date.

- It looks for a new version when it starts and every few hours, and downloads it in the background.
- When one is ready, a card at the bottom left offers "Restart now" or "Later". Later installs it the next time you close AERONEX.
- It never restarts while a flight controller is connected or firmware is being installed, and it waits if you close the app with an aircraft connected.
- Settings → Updates and Help → Check for updates show the version and look for a new one.
